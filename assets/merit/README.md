# Artes de mérito

Dez medalhas originais geradas com a ferramenta integrada **image_gen**, em PNG com transparência. O conjunto foi feito para o jogo Operação Bancada: metal acetinado, esmalte colorido, formas 3D robustas e símbolos legíveis em cartões pequenos.

Os prompts finais completos, um por arte, estão em [prompts.json](prompts.json). Não foi usado o caminho alternativo por CLI/API.

| Arquivo | Uso |
| --- | --- |
| first.png | Primeira faísca |
| investigator.png | Olhar investigativo e Método em ação |
| resilience.png | Um novo olhar |
| power.png | Energia restaurada |
| settings.png | Tudo no ajuste |
| data.png | Guardião dos dados |
| hardware.png | Por dentro da máquina |
| diagnosis.png | Detetive de hardware |
| explorer.png | Explorador do campus |
| champion.png | Grandes descobertas e Legado da Bancada |

O build conserva os originais nesta pasta e cria versões WebP otimizadas, com alpha, em `dist/merit/`. Os textos e critérios ficam em HTML, separados das imagens para facilitar leitura, acessibilidade e manutenção.
